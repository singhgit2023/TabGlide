# TabGlide 1.0.9

- Frontmost browser tabs appear first when browser integration is enabled. Once you navigate or search, loading results preserves your selection.
- First-launch onboarding introduces switching, layouts, Search Mode and permissions. Reopen it from the menu bar’s Onboarding item.
- Search Mode opens immediately with Shift + Command + L by default. Choose alternative hotkeys or disable it in Window Switcher settings or onboarding.
- Search Mode searches running apps, windows and tabs from all running supported browsers when browser integration is enabled. Safari, Chrome, Edge and Brave require Automation permission.
- Search Mode remains open after releasing the shortcut. Type to filter, use arrows or Tab to navigate, Enter to open, and Escape or an outside click to dismiss.

Apple Silicon, macOS 13 or later. This free build is not Apple-notarized.
