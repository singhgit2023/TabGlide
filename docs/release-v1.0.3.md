# WindowHop 1.0.3

- Download, verify, install, and relaunch updates inside WindowHop with Sparkle.
- Optional automatic update checks and automatic download/installation in General settings.
- App icons in the switcher and a compact vertical Dock preview layout.

This is the first Sparkle-enabled version. Install it manually once; future signed releases can install within the app. Apple Silicon, macOS 13 or later. This free build is not Apple-notarized.
