# TabGlide 1.0.8

- From Notch now opens a wide horizontal strip with curved edge connections and smooth slide-in animation.
- Choose a custom background color and Liquid, Frosted, Clear or Solid style.
- Search windows and browser tabs by app name, title or URL, with case-insensitive, accent-insensitive and fuzzy matching. Press / or click Search, release the modifier, then type. Enter opens; Escape or a click outside dismisses.
- Choose Option + Tab, Command + Tab or Control + Tab. Command + Tab replaces the native switcher while TabGlide is running.
- Opt in to tabs from the frontmost Safari, Chrome, Edge or Brave browser. Requires macOS Automation permission. Tab titles and URLs stay in memory. Other browsers are not supported yet.
- Browser tabs load after the picker appears so quick switching is not delayed. Closed or moved tabs fail safely and can be refreshed by reopening the switcher.

Apple Silicon, macOS 13 or later. This free build is not Apple-notarized.
