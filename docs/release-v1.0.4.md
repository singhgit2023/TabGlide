# WindowHop 1.0.4

- Dock hover previews now fit tightly around their window cards, without the large header, footer, and empty background.
- A short fade makes Dock previews open smoothly. Reduce Motion disables the animation.
- Both the preview grid and compact vertical stack retain their window controls and hover selection.

Apple Silicon, macOS 13 or later. This free build is not Apple-notarized.
