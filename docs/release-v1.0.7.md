# TabGlide 1.0.7

- Simplified the menu-bar icon to a filled pair of tabs.
- Added a compact list window switcher with app icons, app names, and window titles.
- Choose Left, Center, Right, or From Notch in Window Switcher settings.
- Notch placement uses top-center below the safe area and also works on displays without a notch.
- Keyboard cycling, pointer selection, and a Settings shortcut are supported.
- Edge placements connect with curved shoulders and slide smoothly into view. Center placement stays floating.
- Smooth opening transition respects Reduce Motion. The existing window-card style remains available.

Apple Silicon, macOS 13 or later. This free build is not Apple-notarized.
