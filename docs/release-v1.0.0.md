# WindowHop 1.0.0

The first public WindowHop build for Apple Silicon Macs.

- Option + Tab switching with recent-window ordering and quick-switch delay.
- Dock hover previews with Close, Minimize/Restore, and normal Quit actions.
- Window thumbnails, hover selection, and wrapping cards.
- General, Dock Previews, and Window Switcher settings.
- Shared System/Light/Dark theme and customizable preview materials and sizing.
- Live permission checks and recovery controls.
- New WindowHop app icon.

## Install

Download `WindowHop-1.0.0-macOS-arm64.zip`, extract it, and move WindowHop.app to Applications. Requires Apple Silicon and macOS 13 or later; thumbnails require macOS 14 or later.

This free build is signed with the maintainer's local certificate, not Apple Developer ID, and is not notarized by Apple. macOS may block opening until you approve it in Privacy & Security. Grant Accessibility for window switching; Screen Recording is optional for thumbnails.

Updates are manual through GitHub Releases. Automated updating is not included. Intel Macs can build from source. The release was compiled and its signature verified; interactive testing remains user-led.
